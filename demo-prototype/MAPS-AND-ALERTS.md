## Try the demo in VS Code

Open demo-prototype/index.html with Live Server, or open the file directly for the offline walkthrough. Under Contacts, pick a Sogod shop. The two addresses represent simulated branches, not a business relationship. Google Maps opens only when you click its link. To show maps inside the page, enable Maps Embed API, restrict the browser key to that API and your HTTP site origin, and enter it in branch-maps.js. Online maps require internet access.

Track DEMO-1042, open Messages, verify with the demo PIN 2468, then select Email or SMS under Alerts. Switch to the assigned technician, open that repair, and publish a valid stage change or a quotation. Track the same ticket again and verify to see the alert. Internal notes do not generate external alerts.

Both channels preview automatically by default. For real email during a local presentation, configure PHP mail with a working mail transport, set the server environment variable REPAIRTRACK_DEMO_EMAIL to your own test inbox, enable USE_LOCAL_EMAIL_RELAY in ticket-alerts.js and serve this directory using PHP on localhost (for example, php -S localhost:8080). Email goes only to that configured inbox. Mail acceptance does not confirm delivery. SMS is simulated. Never place provider secrets in the browser scripts.
